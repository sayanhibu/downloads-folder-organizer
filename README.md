## Downloads Folder Organizer
A beginner and simple Python project that previews files in a folder and, after confirmation, sorts them into category folders. 

## Categories 

- Documents: PDF, DOC, DOCX, TXT
- Images: JPG, JPEG, PNG, GIF
- Audio: MP3, WAV
- Other: all other file types

## Run the program

This program requires Python 3. To start the program, run: 

```
python3 organizer.py
```

## Run the Tests

```bash
python3 -m unittest test_organizer.py
```
